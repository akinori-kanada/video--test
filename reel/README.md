# 縦型リール自動編集（Instagram リール / TikTok・9:16）

撮影した動画を、次のような 1080×1920・30fps の縦型動画に仕上げます。

| レイヤー | 内容 |
|---|---|
| 背面 | 巨大な半透明のボールド文字（例「その髪、諦めないで」）。人物の**後ろ**に入る |
| 人物 | MediaPipe で自動切り抜き。冒頭は背景だけ少し暗くして文字を目立たせる |
| テロップ | 1文字ずつ下から跳ねて着地するキネティックタイポグラフィ。`{ }` で囲んだ語は 1.45 倍の大きさでゴールドに着地 |
| CTA | ラスト 3.5 秒、「保存してカウンセリングで見せてね」のバナーが拡大縮小を繰り返し（パルス）、波紋の枠と下向き矢印が出る |

- **UI 被り対策**：テロップと CTA は、上下 20%・右端 10% を避けた安全エリアに自動で配置し、幅を超える場合は縮小します（`--guides` で禁止ゾーンを赤く表示して確認できます）。
- **フォント**：Noto Sans JP Black / ExtraBold（太めのゴシック体、OFL ライセンス）

サンプル：`samples/demo_reel.mp4`（撮影動画が無いため、スクリーンショット4枚から作った無音の仮素材で作成）

## 使い方

```bash
./setup.sh                                     # 初回のみ：ライブラリ・フォント・切り抜きモデル
python3 render.py --input 撮影動画.mp4 \
                  --script scripts/example_hair.json \
                  --output output/reel.mp4
```

オプション：`--guides`（禁止ゾーン表示）、`--no-cutout`（切り抜きなし）、`--stills 1,5,9`（指定秒の静止画も書き出す）

## 台本ファイル（JSON）

`scripts/example_hair.json` をコピーして編集します。時間は秒です。

```json
{
  "background_text": {"lines": ["その髪、", "諦めないで"], "start": 0, "end": 3.6},
  "telops": [
    {"start": 4.4, "end": 6.6, "text": "本当の原因は\n{頭皮の乾燥}"}
  ],
  "cta": {"text": "保存して\nカウンセリングで見せてね", "start": -3.5}
}
```

- `\n` で改行、`{ }` で強調（ゴールドで大きく表示）
- `cta.start` に負の数を入れると「終わりから何秒前」になります
- テロップごとに `"size"`（基本の文字サイズ、初期値 100）、`"y"`（縦位置、画面の高さに対する割合、初期値 0.64）を指定できます
