- まとめた日: 2026-11-13(本人からもらった要約をもとに作成。数字は動画内の発言で、公式データではない)

## 1. 要点(結論だけ)

1. **TikTokショップの動画は「カートのタップ数」と「購入数」で拡散が決まる。** 普通の投稿(フォロワー獲得・いいね)とは評価のされ方が違う。
2. **売れる構成は「W-CTA」。** フック → 問題提起 → CTA① → 商品説明・ベネフィット → CTA②。1分の動画にCTAを3回入れる人もいる。
3. **尺は60秒前後のほうが購入率が上がりやすい。** 20秒ほどの短い動画より、情報を伝えて背中を押せる。
4. **売上は「投稿本数 × 売れやすい商品」で決まる。** 統計上は12本投稿すれば1本は売れる。月15本を3か月続けると月5〜10万円が狙える。
5. **商品は「売れ筋ランキング上位」かつ「注文数・参加クリエイター数のグラフが右肩上がり」のものを選ぶ。** 最初は報酬率より売れやすさを重視する。
6. **合格ラインは「1万再生あたり5個売れる」。**
7. **今は先行者が有利な時期で、売れている動画をまねるだけで勝てる。** ただ今後は参入者が増えるので、好きなこと・こだわりで専門性を高めておく。

## 2. 仕組みと数字

| 項目 | 内容 |
|---|---|
| TikTokの収益化の柱 | 広告収益/TikTok Lite(ホテル等のアフィリエイト)/TikTokショップ |
| TikTokショップの強み | アプリ内で「見つける → ワンタップで購入」まで完結するので離脱が少ない |
| 報酬率 | 売上の5〜10%ほど(リリース初期は20%の案件もあった) |
| トップ層 | ライブ+動画で月商3〜5億円。動画だけでも上位は月商2,000万円(報酬約200万円)、上位15位以内で月商1,000万円ほど |
| 始める条件 | 原則フォロワー1,000人以上(500〜800人で解放される例もある)。急ぐならプロモート機能に2〜3万円。アカウント購入は審査落ちのリスクがあるので非推奨 |
| ライブと動画 | ライブは1〜2万円の高単価でも売れるが難しい。初心者は3,000〜4,000円前後の商品をショート動画で売るのが王道 |

## 3. 売れる動画の構成(W-CTA)

| 順番 | 中身 | ねらい |
|---|---|---|
| ① フック(冒頭2秒) | 手を止めさせる一言・数字・絵 | 最後まで見てもらう |
| ② 問題提起 | 見る人の悩み・不便を言葉にする | 自分ごとにしてもらう |
| ③ CTA① | 「左下のカートから見られます」など | 興味がある人に早めにタップしてもらう |
| ④ 商品説明・ベネフィット | 使ってどう良くなるか | 買う理由をつくる |
| ⑤ CTA② | 「気になる人はカートからチェック」など | 迷っている人の背中を押す |

- 商品に興味がある人に届くので、CTAを何回入れても離脱にはつながりにくい。
- 世界観やブランディングを作り込まなくてよく、1本で完結した広告として作れば売れる。だから発信経験の少ない初心者でも結果が出やすい。

## 4. 商品の選び方

1. TikTok Studioのマーケットプレイス(クリエイター向けページ)で売れ筋ランキングを見る。
2. 商品ページで「注文数」と「参加クリエイター数」のグラフ(直近7日・30日)を確認し、**どちらも右肩上がり**のものを選ぶ。
3. 最初は3,000円以内の商品を2〜3個買って試す。

おすすめのジャンル:

1. **暮らし(日用品)** — いちばん幅広く、生活に合わせて訴求しやすい
2. **ガジェット** — Anker・Boseなど大手も参入。知識が要るぶん競合が少なく狙い目
3. **美容(スキンケア・垢抜け・筋トレ)** — ReFaなど大手が参入して市場が熱い。普通の投稿とも相性が良い
- 番外:**食品** — 無料サンプルがたくさん届きやすい

## 5. 最初の一歩(動画で紹介された手順)

1. 3,000円以内で、ランキング上位かつグラフが右肩上がりの商品を2〜3個買う。
2. その商品で売れているクリエイターの動画を3〜5本見て**全部文字起こし**し、冒頭のフックと訴求のパターンを分析する。
3. 自分のアカウントに合わせてまねて作り、まず3本投稿する。

## 6. @a.kanada の動画づくりにどう活かすか

いまのスキル(約25秒・最後にシェアの一言・3つの「伸びている型」)と照らし合わせた結果。

| 動画で言っていたこと | いまのやり方 | 変えること |
|---|---|---|
| 評価されるのは**カートのタップ数と購入数** | シェア率の改善を最優先にしていた | **CTA(カートへの誘導)を最優先**にする。シェアの一言は最後に残すが、CTAより後ろに置く |
| W-CTA(CTAを2回) | 購入への一言は最後に1回 | **問題提起の直後にCTA①、説明の後にCTA②**を入れる。テロップにも出す |
| 60秒前後のほうが買われやすい | 約25秒 | **要相談**。標準の25秒は残しつつ、説明する価値がある商品で45〜60秒版を試す案(下の「決めてほしいこと」) |
| 売れている動画をまねる | 自分の3つの型から選ぶ | 同じ商品で売れている動画があれば、そのフックと訴求を参考にする(本人に文字起こしをもらう) |
| 1万再生あたり5個が合格ライン | 再生数・シェア率で振り返っていた | **振り返りに「1万再生あたりの販売数」**と「カートのタップ数」を加える |
| 12本に1本売れる・月15本 | 本数の目安なし | 目安として「月15本・まず3か月」を共有する |
| 商品選びの基準 | 商品は本人が決める | 本人から相談されたら、ランキング+右肩上がりグラフ+3,000円前後で候補を出す |
| ジャンル(暮らし・ガジェット・美容/筋トレ) | 姿勢改善・ピラティスボード・イヤホン・食品などが好調 | 「50歳・体脂肪率1ケタ」の強みと相性がいい**筋トレ・体づくり系**と**ガジェット**は勝ち筋と一致。こだわりで専門性を出す方針とも合う |
